# S3 · shot_boundary  (Fighting018_x264)

Finds hard cuts by combining an HSV histogram distance with an edge-change ratio, then splits the video into shots.
Why: a clip spanning a cut mixes two unrelated scenes (edited/compilation footage).
Notice: the red lines in plot.png; left/right images are the frames either side of the strongest cut.

Files: compare.png, input.gif, input.png, metrics.json, output.png, params.json, plot.png
