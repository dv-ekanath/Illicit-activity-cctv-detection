# S1 · metadata  (Normal_Videos_722_x264)

Reads container/stream metadata (codec, resolution, nominal vs measured FPS, VFR flag, bitrate, duration).
Why: decides how S2 must resample and flags corrupt or unusable videos.
Notice: nominal and measured FPS agree and the video is constant-frame-rate.

Files: compare.png, input.png, metrics.json, output.png, params.json
