# S7 · bytetrack_ids  (Fighting018_x264)

ByteTrack links the YOLO detections across frames, giving each person a persistent ID and a trajectory.
Why: speed and distance between people (interaction signals) need identities over time; this also replaces the never-committed tracker.py.
Notice: IDs stay constant while people move; coloured tails are the last 2 s of foot positions.

Files: compare.png, input.gif, input.png, metrics.json, output.gif, output.png, params.json
