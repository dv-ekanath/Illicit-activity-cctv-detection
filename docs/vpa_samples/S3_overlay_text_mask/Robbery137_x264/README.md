# S3 · overlay_text_mask  (Robbery137_x264)

Finds timestamps / logos / captions as recurring high-contrast strokes in the border band, then inpaints them.
Why: a camera-specific timestamp is a shortcut the model can learn instead of the action.
Notice: red boxes = detected overlay, middle = region mask, right = frame after inpainting; none found -> unchanged.
